PHASE SURFER v41 — CARD WASH / COLD SPLIT LAB

v40を基準に、音・操作は変更せずカード識別だけを調整。

変更:
- 各レコードfamilyに3%の薄い「紙色」washを追加。
- LIVEアンバー（針 / CURRENT BPM）はそのまま専用色。
- 近かったICE BLUEとTEALを実機で見分けやすい方向へ分離。
  - ICE BLUE: 文字色を明るく・高彩度・わずかにクール側。
  - ICE BLUE: 枠をわずかに明るく。
  - ICE BLUE wash: 文字より暗いクールシアン。
  - TEAL wash: さらに暗い深いティール。
- 赤 / 紫 / マゼンタ / 緑 / コバルト / 白も3% washを持つ。

目的は配色の美しさより「演奏中に一目でfamilyを識別できること」。
